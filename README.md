# 多項式實驗室｜3-3 多項式函數的圖形與多項式不等式

高一數學 3-3「多項式函數的圖形與多項式不等式」的課堂複習遊戲，沿用「指對數實驗室」的畫面與玩法。
大螢幕分成左、中、右三區，三位同學同時上台、各玩各的；一位玩完就能立刻換下一位。

- 純前端靜態網頁，**不需要安裝、不需要編譯**，放上 GitHub Pages 就能用。
- 也可以直接在電腦上雙擊 `index.html` 開啟（教室網路斷線時的備案）。
- 支援 Chrome、Edge。
- 設定存在瀏覽器裡，和「指對數實驗室」**分開存放**，兩個遊戲放在同一個 GitHub 帳號下也不會互相蓋掉。

---

## 一、放上 GitHub Pages

### 方法 A：用網頁上傳（最簡單）

1. 在 GitHub 建立新的 repository，例如 `poly-lab`，設為 **Public**。
2. 進入 repository → **Add file → Upload files**。
3. 把解壓縮後資料夾「裡面」的所有檔案與資料夾拖進去（`index.html` 要在最上層，不要多包一層資料夾）。
   - 資料夾裡有一個隱藏檔 `.nojekyll`，如果檔案總管沒顯示也沒關係，少了它網站一樣能運作。
4. 按 **Commit changes**。
5. 到 **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
6. 約 1 分鐘後，網址會是：`https://你的帳號.github.io/poly-lab/`

### 方法 B：用 git

```bash
cd poly-lab
git init
git add .
git commit -m "多項式實驗室"
git branch -M main
git remote add origin https://github.com/你的帳號/poly-lab.git
git push -u origin main
```

之後一樣到 **Settings → Pages** 開啟（同上第 5 步）。

## 二、教室設定（Surface Pro 8 ＋ ViewSonic IFP8653）

與指對數實驗室相同：

1. **上課用全功能 USB-C 線**連接，畫面與觸控走同一條線，三人同時觸控最穩定（AirSync 只當備用）。
2. **觸控測試**：長按右上角「⚙ 設定」2 秒 → 「開始觸控測試」，三位同學同時拖曳，「最多同時」要到 3。
3. **關閉 Windows 三指／四指觸控手勢**：設定 → 藍牙與裝置 → 觸控。
4. **用 Kiosk 模式開啟**（最能防止學生亂點），捷徑「目標」填：

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --user-data-dir="C:\PolyLabKiosk" https://你的帳號.github.io/poly-lab/
   ```

   離開 Kiosk 按 **Alt＋F4**。Kiosk 視窗用的是獨立設定檔，請在 Kiosk 視窗裡調整設定。

不使用 Kiosk 時，可按右上角「⛶ 全螢幕」；全螢幕時要**長按 1.5 秒**才會離開。

## 三、上課怎麼玩

1. 三位同學各站一區，按「開始挑戰」。
2. 每人依序玩開啟的關卡（預設 8 關），每關一道挑戰題。
3. 玩完顯示總分與每關結果，「再玩一次」約 3 秒後亮起，下一位同學按它就直接開始。

### 計分規則

| 情況 | 結果 |
|---|---|
| 答對 | 15 分＋剩餘秒數 |
| 主動按「求救卡」 | 出現提示，扣 10 秒（每關一張） |
| 第一次答錯 | 自動用掉求救卡：出現提示、扣 10 秒，可以再答 |
| 再次答錯，或時間到 | 本關 0 分，顯示正解，5 秒後自動進入下一關 |

### 八個關卡

| 關卡 | 玩法 | 複習內容 | 簡單／標準／挑戰 |
|---|---|---|---|
| 1 曲線配對站 | 把 2 個函數拖線接到它的圖形（3 張圖，1 張用不到） | $y=ax^3+px$ 的圖形特徵、大域特徵 | $a$、$p$ 正負號／同一視窗比爬升快慢與 $p=0$／因式分解式看交點與重根 |
| 2 平移對準 | 拖曳 $y=ax^3+px$ 的整條曲線，把對稱中心放到正確位置後「鎖定」 | 三次函數圖形的平移、對稱中心 | 已寫成 $a(x-h)^3+p(x-h)+k$／展開式 $a=\pm1$／展開式 $\lvert a\rvert\ge2$ |
| 3 放大鏡 | 拖斜率滑桿，直線從點 $P$ 長出；答對鏡頭放大到曲線與直線重合 | 一次近似（課本圖 21、22） | 已寫成 $(x-h)$ 的冪次／三次展開式／四次或首項較大 |
| 4 觀念法庭 | 敘述卡成立往右滑（或按 ○），不成立往左滑（或按 ✗） | 圖形、對稱中心、一次近似、不等式觀念 | 3 句／3 句／4 句 |
| 5 拆彈小組 | 用手指劃過電線，剪斷正確答案 | 一次不等式、二次不等式（含無解、所有實數、$x\ne a$） | 可分解／判別式與配方／首項為負、分數根 |
| 6 正負號訊號燈 | 把數線上每一段點成 ＋ 或 －，按「通電」；答對自動點亮解 | 高次不等式：分析每個因式的正負號（課本表 6） | 給各因式的正負列／含平方、三次方、恆正二次式／再加負首項、分數根 |
| 7 解集合雷射 | 看 $y=f(x)$ 圖形，點亮數線上成立的區段，點端點切換 ●／○ | 看圖解不等式（含重根、孤立解、挖掉的點） | 單根／多一個重根／四、五次式 |
| 8 多項式雲霄飛車 | 四選一，答對 3D 雲霄飛車沿三次曲線軌道衝進終點 | 綜合：恆正因式的不等式、平移與對稱中心、一次近似、恆成立求範圍 | 依難度分題庫；三種難度都只出可以心算的題目（整數、一兩步算完，不出小數估計或根號範圍） |

- 第 1、2、3、6、7 關的題目是**依難度隨機產生**的，數字都控制成可以心算（整數根、整數對稱中心、整數斜率）。
- 第 4、5、8 關從題庫隨機出題，並避開三區最近出過的題目。

## 五、修改題目

| 檔案 | 內容 |
|---|---|
| `js/levels/l4-court.js` | `S(敘述, 是否成立 true／false, 提示, 理由, 驗算)`，分 `easy`、`normal`、`hard` |
| `js/levels/l5-bomb.js` | `Q(代號, 題目, [正解, 干擾1, 干擾2, 干擾3], 提示, 解說, 驗算)`，**選項第一個是正解**，畫面上會自動打亂 |
| `js/levels/l8-coaster.js` | 格式同上 |
| `js/levels/l1-match.js` 等 | 第 1、2、3、6、7 關由程式產生題目，範圍寫在各檔的 `gen` / `build` 函式裡 |

數學式用 `$...$` 包起來，寫法與 LaTeX 相同。注意 JavaScript 字串裡的反斜線要寫兩個，例如 `'$x\\le-3$'`。
「驗算」只給自動測試用，新增題目時可以填 `null`。

## 六、檔案結構

```
poly-lab/
├─ index.html              主頁面
├─ .nojekyll
├─ css/style.css           樣式（各區尺寸依區域大小自動縮放，不需捲動）
├─ js/
│  ├─ main.js              啟動與主迴圈

│  ├─ fx.js                粒子特效

├─ vendor/
│  ├─ katex/               數學式排版（KaTeX 0.16.22，MIT 授權）

```

## 七、疑難排解

| 狀況 | 處理方式 |
|---|---|
| 觸控沒反應或點不準 | 確認使用 USB-C 線；用設定頁的「觸控測試」檢查；必要時做 Windows「平板電腦設定」的觸控對應 |
| 三人同時操作時卡頓 | 設定頁把「畫面解析度」調成 75% 或 50%，「特效」改成精簡 |
| 第 8 關沒有 3D 畫面 | 電腦不支援 WebGL 時會自動改用 2D 動畫，遊戲照常進行 |
| 網路斷線 | 直接雙擊電腦上的 `index.html` 開啟（設定需在該視窗重新調整） |
